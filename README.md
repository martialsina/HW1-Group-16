# Deep Learning Homework 1: Image Classification with PyTorch

This repository contains the first homework assignment for the Deep Learning course. You'll walk through a full image-classification pipeline in PyTorch — from training a linear classifier, to building a shallow neural network, and finally experimenting with architectural and training variations to analyze their impact on performance.

---

### Part 1a: Training a Linear Classifier on Fashion-MNIST

In this part, you'll build and train a simple image classifier using PyTorch on the Fashion-MNIST dataset, which contains grayscale images of clothing items. You'll implement a linear model (or shallow neural network) to classify images into 10 categories, practicing model definition, training loops, evaluation, and performance measurement.

**Deliverables:** Implement all required code in `image_classification_shallow.ipynb`.

---

### Part 1b: Experimental Analysis of a Shallow Neural Network

Neural networks are flexible function approximators, but their performance is highly sensitive to architecture and training parameters. In this part, you'll systematically study how different hyperparameters and training strategies affect a shallow neural network's performance on Fashion-MNIST. These experiments will build your intuition for practical model tuning and performance tradeoffs in real-world settings.

Find the instructions for this part [here](hw_1b.md).
